## DNA Sequence Analysis Toolkit 🧬

A beginner bioinformatics project developed using Python and Biopython.

This project explores fundamental DNA sequence analysis techniques, including nucleotide counting, GC and AT content calculation, sequence validation, DNA transcription, RNA translation, and basic Open Reading Frame (ORF) detection.

It also demonstrates how biological sequences can be processed using FASTA files and visualized through Python.

## Project Features

- DNA sequence input and nucleotide counting.
- GC and AT content calculation.
- DNA sequence validation.
- Complement and reverse complement generation.
- DNA transcription into RNA.
- RNA translation into protein.
- Codon identification.
- Basic Open Reading Frame (ORF) detection.
- FASTA file creation and sequence analysis.
- DNA composition visualization using Matplotlib.
- Testing and error handling.


## Technologies Used
